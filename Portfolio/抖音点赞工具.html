核心源码（任务循环）

工具通过 pyautogui 模拟键鼠、pynput 监听热键，核心是一个循环任务：点击视频区 → Z 键点赞 → 点击收藏 → 等待间隔 → ↓ 切下一个。 

def task_loop(mode, like_x, like_y, fav_x, fav_y, interval):
    global RUN_TASK
    count = 0
    while RUN_TASK:
        # ① 点赞：先点击视频区确保焦点，再按 Z
        if mode in ("like", "both"):
            if like_x > 0 and like_y > 0:
                pyautogui.click(like_x, like_y)
                time.sleep(0.2)
            pyautogui.press("z")          # 抖音网页版点赞快捷键
            time.sleep(0.15)

        # ② 收藏：鼠标点击收藏坐标
        if mode in ("favorite", "both"):
            if fav_x > 0 and fav_y > 0:
                pyautogui.click(fav_x, fav_y)
            time.sleep(0.15)

        count += 1
        print(f"✓ 第 {count} 个作品 · 完成")

        # ③ 等待切换间隔
        elapsed = 0
        while RUN_TASK and elapsed < interval:
            time.sleep(0.1)
            elapsed += 0.1

        # ④ 切换到下一个作品
        if RUN_TASK:
            pyautogui.press("down")
            time.sleep(0.3)

    print("✅ 任务循环已终止")
